About

Focus Areas

Agentic Loop Engineering

Designing robust feedback loops for LLM agents that can plan, act, and reflect without falling into infinite loops or context bloat.

Probabilistic Memory Systems

Building memory layers that use Bloom filters, HyperLogLog, and count-min sketches to store agent knowledge with bounded error and efficient forgetting curves.

MCP Integration

Developing Model Context Protocol servers that bridge language models with real-world tools, APIs, and data sources.

Rust for AI Infrastructure

Leveraging Rust's performance and safety guarantees to build the systems-level components that AI agents depend on — memory allocators, embedding storage, and async runtimes.
